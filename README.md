# MuZiC

קטלוג של מוזיקה פרסית למסיבות ולחתונות: שירים, BPM, סולם (Camelot) והצעות לשיר הבא.

- `index.html`: דף הקטלוג (עברית/English)
- `data/build_catalog.py`: הנתונים והמקורות שלהם. מריצים `python3 data/build_catalog.py` כדי לייצר מחדש את `data/songs.js`

כלל: ממלאים שדה רק כשיש לו מקור. BPM, סולם וז׳אנר של טראקים מ-Beatport הם הנתונים של Beatport.
